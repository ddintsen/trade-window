# Token logos

These files come unchanged from Onbloc's gno-token-resource repository
(https://github.com/onbloc/gno-token-resource, commit aaae1170775a, October
2026), the token list that Adena, GnoScan and GnoSwap read. The repository
invites any product to use its token resources and is published under the
MIT license, copyright (c) 2023 Onbloc. Each logo stays the mark of its
token's project; Trade Window shows it only to say which token an item is.
